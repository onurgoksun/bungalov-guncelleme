# Bungalov Yönetim · Güncellemeler

Bu depo, Bungalov Yönetim uygulamasının otomatik güncelleme paketlerini barındırır.
Uygulama açılışta `surum.json` dosyasına bakar; yeni bir sürüm varsa `paketler/` altındaki
paketi indirip doğrular (SHA-256) ve kullanıcı onaylayınca devreye alır.

Bu depoda müşteri / rezervasyon verisi bulunmaz.
